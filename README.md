# Offline Authentication Flow Demo

A static, fictional UI mock-up for learning how an example profile response may be presented. It does not authenticate users or connect to any game or identity provider.

## Safety by design

- No login links or identity-provider buttons
- No password, callback URL, or token input
- No external token API, network requests, or remote scripts
- No access-token or JWT generation
- Only fictional sample data is shown

Never paste passwords, callback URLs, EAT tokens, access tokens, or JWTs into third-party tools. This project is not an account recovery or token-generation service.

## Run locally

Open `index.html` in a browser. No package installation or server is required; the page is self-contained and works offline.
